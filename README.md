# Обучение диффузионной модели на датасете котов

Этот проект посвящен реализации и обучению диффузионной модели (DDPM) для генерации изображений котов с использованием библиотеки `diffusers`.

## Выбранный датасет
- **Название**: [huggan/few-shot-cat](https://huggingface.co/datasets/huggan/few-shot-cat)
- **Количество изображений**: 160
- **Предобработка**: 
  - Ресайз до 64x64 пикселей.
  - Случайное горизонтальное отражение (аугментация).
  - Нормализация значений пикселей в диапазон `[-1, 1]`.

## Архитектура модели
- **Тип**: UNet2DModel (библиотека `diffusers`).
- **Параметры**:
  - `block_out_channels`: (128, 128, 256, 256, 512, 512).
  - `down_block_types`: сочетание обычных ResNet-блоков и блоков с Attention.
  - **Количество шагов диффузии**: 1000.
  - **Расписание шума**: Линейное (Linear Noise Schedule).

## Запуск
Для воспроизведения результатов выполните следующие команды:

1. **Установка зависимостей**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Обучение**:
   Откройте ноутбук `diffusion_training_hf.ipynb` и запустите все ячейки. Обучение настроено на 500 эпох.

3. **Генерация**:
   В ноутбуке реализованы функции для сравнения методов:
   - **DDPM**: 1000 шагов (стохастический процесс).
   - **DDIM**: 50 шагов (детерминированный ускоренный процесс).

## Результаты

### График Loss
В процессе обучения использовалась функция потерь MSE (Mean Squared Error) между предсказанным и реально добавленным шумом. Лосс стабильно снижался на протяжении 500 эпох.

### Сравнение DDPM и DDIM
Замеры проводились на устройстве Apple M-series (MPS):

| Метод | Количество шагов | Время генерации (4 фото) | Качество (субъективно) |
|-------|------------------|--------------------------|-------------------------|
| DDPM  | 1000             | ~48.45 сек               | Высокая детализация     |
| DDIM  | 50               | ~2.39 сек                | Сопоставимое качество   |

**Вывод**: DDIM позволяет ускорить генерацию более чем в **20 раз** при минимальной потере визуального качества.

## Мини-эксперименты
1. **Влияние шагов DDIM**: Протестированы значения [10, 20, 50, 100]. При 10 шагах заметны артефакты, оптимальный баланс достигается на 50 шагах.
2. **Расписание шума**: Косинусное расписание (`squaredcos_cap_v2`) показало более плавное зашумление на ранних этапах по сравнению с линейным.
3. **Conditioning**: Эксперимент по генерации с условием не проводился в полной мере из-за отсутствия меток классов в текущем датасете (все изображения — коты).

## Выводы
- Удалось реализовать полный цикл обучения диффузионной модели "с нуля".
- Модель успешно выучила цветовую гамму и базовые формы объектов даже на очень маленьком датасете (160 фото).
- Подтверждена эффективность алгоритма DDIM для быстрого сэмплинга.
